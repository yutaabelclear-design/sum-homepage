
## 見方
1. このフォルダを開く
2. `index.html` をダブルクリック
3. トップページの「ページ一覧」カードやヘッダーから、各詳細ページへ移動できます。

## 追加したページ
- `overview.html`：チーム概要
- `activity.html`：活動内容
- `members.html`：メンバー紹介
- `vehicle.html`：車両紹介
- `sponsors.html`：スポンサー紹介
- `recruit.html`：新入部員募集
- `results.html`：大会実績
- `contact.html`：お問い合わせ
- `news.html`：お知らせ
- `gallery.html`：ギャラリー

## 注意
- 画像・ロゴ・SNSリンクは仮です。
- 電話番号は公開向けに `080-XXXX-XXXX` としています。公開する場合は、チーム共用メール、Googleフォーム、公式SNSへの差し替えを推奨します。
- お問い合わせフォームは見た目だけです。実際に送信するにはGoogleフォームや外部サービスとの接続が必要です。
